- create a branch:
    git branch <branch_name>

- delete a branch
    git branch -d <branch_name>

- check branch ptr
    git log

    - check branch details (pushes, etc)
        git log --decorate
    
    - check branch details (change comments closer together)
        git log --oneline --decorate

- switch branch ptr
    git checkout <branch_name>

- push local branch to remote (master)
    git push origin <branch_name>:master

    - to remove those files
        git pull    - this will get up-to-date branch info
        git rm <file_name>
        git commit -m "message"
        git push

----- THINGS TO KEEP IN MIND -----
- To pull updated content, you must execute the following
    git stash
    git pull origin <branch_name>
    git stash pop 

- Now the changes should be displayed to see differences
